# Contributing

Bug reports and pull requests are welcome.

Please include:

- OS and version
- Hardware model
- SysMon One version
- Steps to reproduce
- Terminal output or screenshot
- Whether the issue reproduces consistently

For hardware/sensor issues, please do not assume a missing sensor value is a bug.
Different vendors and Apple SoCs expose different telemetry.

Please do not submit code that:

- adds telemetry
- silently deletes personal files
- requires unnecessary administrator privileges
- fabricates unavailable sensor values
